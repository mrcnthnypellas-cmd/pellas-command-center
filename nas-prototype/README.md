# Private Server — Phase 1 prototype

An interactive, click-through prototype of the proposed private NAS / server software.

**Open `index.html` in any modern browser.** It needs no install, no server and no internet connection.

## What this is

- A visual prototype only. Every drive, file, user, device, backup and log entry is **simulated demo data** kept in memory.
- It does **not** read your disks or files, touch network interfaces, or contact any external server. It makes no network requests (it uses only system fonts).
- Reloading the page resets everything. **Settings → System → Reset demo** does the same.

## Pages

Dashboard · Storage · File Manager · Users · Permissions · Remote Access · Security · Backup · Activity Logs · System Info · Settings (9 sections) · First-time Setup Wizard (7 steps) · Sign-in screen (via the account menu → Sign out)

## Things to try

- **File Manager:** open folders, search, sort, switch list/grid view, create/rename/delete folders, simulated upload/download
- **Users:** add, edit, disable or delete a user
- **Permissions:** click a cell to cycle the access level; toggle system permissions
- **Remote Access:** turn it off and on, run the connection test, connect a new device
- **Backup:** Backup now, restore, history, schedule settings
- **Setup wizard:** the button at the bottom of the sidebar
- **Theme:** the moon/sun button in the top bar (light/dark)
- Resize to phone width to see the mobile menu
